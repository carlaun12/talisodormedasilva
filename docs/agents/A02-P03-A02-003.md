## Product Owner decisions recorded

### PD-006 — Android support floor

**DECIDED**

The current product minimum supported Android version is **Android 15 / API 35**.

Consequences:

- Android versions below API 35 are **OUT OF SCOPE**;
- older Android support is not a current requirement;
- implementation must use `minSdk = 35`;
- any earlier ambiguity around API 23 or another lower compatibility floor is superseded;
- a future Product Owner decision may revise the floor.

### PD-007 — Current-device-only financial data

**DECIDED**

Product financial data must remain only on the current local device.

For the current product, the following are disabled:

- Android cloud backup;
- device-to-device application data transfer;
- cloud synchronization;
- backend/server persistence;
- account-based remote restore.

No remote backup, remote copy, synchronization, or device-migration requirement may be inferred.

A future Product Owner decision may revise this policy.
